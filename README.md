# Online Stamp Doc - Free Online Stamp Maker

Professional digital stamping and document management tool. Design custom stamps and apply them to any PDF or image — free, instant, and 100% private.

![Online Stamp Doc](favicon.svg)

## 🚀 Features

- **Custom Stamp Designer**: Create circular, rectangular, rounded, diamond, star, triangle, and hexagon stamps.
- **Handwritten Signature**: Draw your own signature and turn it into a digital stamp instantly.
- **Quick Templates**: One-click presets for common stamps like PAID, APPROVED, URGENT, and CONFIDENTIAL.
- **Realistic Distress Effect**: Advanced noise algorithm to simulate real ink on paper.
- **100% Private**: All processing happens locally in your browser. Your documents are never uploaded to any server.
- **PDF & Image Support**: Apply stamps to PDF, JPG, and PNG files.
- **Advanced Controls**: Rotate, resize, and position your stamps with pixel-perfect accuracy.

## 🛠️ Technology

- **PDF.js**: For high-performance PDF rendering in the browser.
- **PDF-lib**: For modifying PDF document structures and embedding stamps.
- **HTML5 Canvas**: For the real-time stamp preview engine.
- **Generative AI**: Enhanced logic and design optimization.
